# Project instructions

Read [docs/spec.md](docs/spec.md) before making changes — it documents the actual current state of the app (stack, data model, routes, conventions). [docs/food-planner-product-vision.md](docs/food-planner-product-vision.md) is the product vision/requirements doc; spec.md is what's actually built.

**Whenever you change app behavior, data model, routes/actions, dependencies, or resolve one of the vision doc's open questions, update `docs/spec.md` in the same turn.** See the "Keeping this spec updated" section at the bottom of that file for exactly what triggers an update. Do not treat this as optional cleanup — an out-of-date spec is worse than no spec, since future sessions (yours or otherwise) will trust it.
